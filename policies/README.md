# Policy interfaces

`xpolicylab/` contains the End-to-end (VLA / WAM) observation/action adapter. `roboprobe/`
contains the bridge for multimodal agents. Shared transport and protocol helpers remain
alongside them. These are adapters, not bundled model checkpoints or a claim that
every supported transport has completed the new development-layout GPU campaign.

## agents acting through tools

Multimodal agents act through structured tool calls. The agent runtime executes
these calls against the robot environment and returns public observations.

XPolicyLab is an external dependency pinned in `pyproject.toml` to
`128e626278ef753fa8a86b16e3425a6359388b4c`. No unqualified new model training scripts
or weights have been added. Per-model training recipes will be exported only with
the corresponding verified version, command, dependencies and GPU configuration.
