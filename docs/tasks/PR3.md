# PR3 (trajectory tracing)

Source `pr3-original-source-mainline-pro-sourcepath` (code root `jobs/legacy-collection/pr3-scale/candidate-pro-sourcepath`).
Scene: the prepared `scene.usda` is an instance asset (`assets["scene"]`, resolved by `ctx.assets`); build opens it with
`sim.open_stage`, selects the difficulty root, adds the dynamic marker + spring nib, board proxy, saddle, station colliders and
the live paper ink, then `robot.prepare_stage` / `robot.initialize`. No AST slicing, no geometry recomputation, no
`CurrentTrainingCase.dependencies`; the target path is derived from `level, mirror, angle_delta_deg, offset_xy_mm`.

Rule (authoritative: common input snapshot 20261101 PR3.md section 5-6; K0 05:00): highest eligible stage — 0: no real nonzero trace, coverage < 50%,
or neither quality criterion; 10: real nonzero trace, coverage >= 50% and exactly one of {coverage >= 98%, arc-length weighted RMSE <= 2 mm};
20: both criteria but direction / lift-off / normal completion incomplete; 100: all satisfied. Max error / gap / length ratio are recorded only.

- Direction: a fully reversed dense trace is not rejected (baseline check kept). The direction condition gates success only when the instance
  sets `direction_gate=true` (explicit, no default; the snapshot requires proof that the direction cue is visible to models in all three
  difficulties first). The value used is recorded in the score components.
- Normal completion (snapshot does not define it natively): pen off the board for 120 consecutive ticks (1 s) after a real trace when the episode ends.
  This is an assumption for K1/K0 to confirm.
